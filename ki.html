Media Pembelajaran Berbasis Gamifikasi

DETEKTIF DATA
Kasus Nilai Misterius

Sebuah media pembelajaran gamifikasi untuk materi Microsoft Excel yang mengajak siswa menjadi tim detektif dalam menemukan kesalahan data menggunakan fungsi SUM, AVERAGE, SORTING, dan FILTERING.

Latar Belakang Pengembangan Media

🚨

Permasalahan

  • Siswa masih pasif saat belajar Excel.
  • Pembelajaran didominasi ceramah.
  • Sulit menganalisis kesalahan data.
  • Hasil belajar belum optimal.
💡

Inovasi

Mengembangkan media pembelajaran berbasis gamifikasi Detektif Data yang menghadirkan studi kasus manipulasi nilai sehingga siswa belajar melalui misi investigasi menggunakan Excel.

🧩

Solusi

Siswa bekerja dalam kelompok beranggotakan tiga orang untuk menyelesaikan lima misi bertahap menggunakan fitur SUM, AVERAGE, SORTING, dan FILTERING.

📈

Tindak Lanjut

  • Mengembangkan variasi level Game Detektif Data untuk materi analisis data lainnya
  • Mengujicobakan media pada kelas lain
  • Menjadikan game detektif data menjadi media digital

🕵️ Lima Misi Detektif Data

Setiap kelompok menyelesaikan misi secara berurutan. Misi berikutnya hanya dapat dibuka apabila misi sebelumnya berhasil diselesaikan.

LEVEL 1

Misi 1 — SUM

Menghitung total nilai seluruh siswa menggunakan fungsi SUM, kemudian menemukan data yang memiliki nilai tidak wajar sebagai bukti awal investigasi.

LEVEL 2

Misi 2 — AVERAGE

Menghitung rata-rata nilai setiap siswa dan menganalisis apakah terdapat rata-rata yang terlalu tinggi atau terlalu rendah akibat kesalahan data.

LEVEL 3

Misi 3 — SORTING

Mengurutkan data berdasarkan nilai rata-rata tertinggi hingga terendah, lalu mengidentifikasi posisi siswa yang terlihat mencurigakan.

LEVEL 4

Misi 4 — FILTERING

Menampilkan hanya siswa dengan nilai ≥ 80 menggunakan fitur Filtering, kemudian memastikan tidak ada data yang lolos karena kesalahan input.

FINAL MISSION

Siapa Pelaku Manipulasi Data?

Siswa menggabungkan hasil SUM, AVERAGE, SORTING, dan FILTERING untuk menemukan data yang dimanipulasi serta memberikan alasan berdasarkan bukti.

🎯 Tujuan Pembelajaran

Melalui media gamifikasi Detektif Data, siswa tidak hanya menghafal rumus Excel, tetapi juga mampu berpikir kritis, menganalisis kesalahan data, bekerja sama dalam tim, serta menyelesaikan masalah nyata menggunakan Microsoft Excel.
